# Architecture

## Overview

The hybrid search engine combines keyword search (BM25) and semantic search
(vector embeddings) into a single ranked result list. A tunable alpha
parameter controls the blend at query time — no reindexing required.

The system has four runtime components:
```
┌─────────────────┐     HTTP      ┌──────────────────┐
│   Streamlit     │ ────────────► │   FastAPI        │
│   dashboard     │               │   :8000          │
│   :8501         │ ◄──────────── │                  │
└─────────────────┘               └────────┬─────────┘
                                           │
                          ┌────────────────┼────────────────┐
                          │                │                │
                   ┌──────▼──────┐  ┌──────▼──────┐  ┌─────▼──────┐
                   │  BM25       │  │  Vector     │  │  SQLite    │
                   │  index      │  │  index      │  │  logs      │
                   │  (pickle)   │  │  (FAISS)    │  └────────────┘
                   └─────────────┘  └─────────────┘
```

## Components

### Ingest pipeline (`backend/app/ingest.py`)

Fetches Wikipedia articles via `wikipedia-api` across 12 topic categories,
cleans and truncates text, and writes one JSON object per line to
`data/processed/docs.jsonl`. Local `.txt` files dropped into `data/raw/`
are included automatically. Each document carries a stable `doc_id`, title,
text, category, source URL, and creation timestamp.

### BM25 index (`backend/app/search/bm25.py`)

Built with `rank-bm25` (BM25Okapi). Documents are tokenised by lowercasing
and stripping punctuation. The fitted model and document list are pickled
together to `data/indexes/bm25/`. At query time, raw BM25 scores are
min-max normalised to [0, 1] before fusion.

### Vector index (`backend/app/search/vector.py`)

Documents are encoded with `sentence-transformers` (`all-MiniLM-L6-v2`,
384 dimensions). Embeddings are L2-normalised before insertion into a FAISS
`IndexFlatIP`, making inner product equivalent to cosine similarity. The
FAISS index, a position-to-doc_id map, and a meta.json (model name,
dimension, corpus hash) are saved to `data/indexes/vector/`.

### Hybrid fusion (`backend/app/search/hybrid.py`)

Each index independently returns up to 30 candidates. Their doc_id sets are
unioned, missing scores are filled with 0.0, and each score space is
min-max normalised independently. Fusion:
```
hybrid = alpha × bm25_norm + (1 − alpha) × vector_norm
```

When all scores in a space are equal (including all-zero from a nonsense
query) the normaliser returns 0.5 for every document rather than NaN.

### API (`backend/app/api/`)

FastAPI application with three routers:

| Router | Endpoints |
|---|---|
| `search.py` | `POST /api/v1/search` |
| `ingest.py` | `POST /api/v1/ingest` |
| `stats.py` | `GET /api/v1/stats`, `/logs`, `/metrics`, `/health` |

Indexes are loaded once at startup inside a lifespan context manager and
injected into routes via FastAPI's dependency injection. If indexes are
absent at startup the API starts anyway and returns 503 on search requests
until indexes are built. Rate limiting is applied at 100 requests per
minute per IP via `slowapi`.

### Query logging (`backend/app/db.py`)

Every search request — including failed ones — is logged to SQLite
(`data/search_logs.db`). The schema is versioned via a `schema_meta` table
and migrated incrementally on startup. Writes are dispatched with
`asyncio.to_thread` to avoid blocking the event loop.

### Dashboard (`frontend/dashboard.py`)

Four-page Streamlit application:

- **Search** — interactive search with per-result score breakdown charts
- **KPIs** — query volume, latency percentiles, top queries
- **Evaluation** — nDCG, Recall, MRR across alpha values
- **Debug Logs** — filterable log viewer with error highlighting

### Evaluation (`backend/app/eval.py`)

Loads `eval/qrels.json` (25 queries with graded relevance judgments
generated by `generate_qrels.py`) and sweeps alpha in [0.0, 0.25, 0.5,
0.75, 1.0], computing mean nDCG@k, Recall@k, and MRR across all queries.
Results are written to `data/metrics/experiments.csv`.

```
     ▼

                                               │
                              ┌────────────────┼────────────────┐

                  scripts/build_index.py               (same docs)
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
   data/indexes/bm25/               data/indexes/vector/

   meta.json                        meta.json
                                    id_map.json
               │                             │
               └──────────────┬──────────────┘
                              ▼
                     app/search/hybrid.py
                              │
                              ▼
                       api/main.py (FastAPI)
                              │
                    ┌─────────┴──────────┐
                    ▼                    ▼
             HTTP response          app/db.py
                                   (SQLite log)
```
